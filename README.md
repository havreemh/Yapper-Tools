**Yapper Tools** (unofficial Chrome extension for yapper.website)

Adds the stuff Yapper doesn't have yet:

🔇 **Mute people in chat.** Hover any message and click the 🔇 to hide that person's messages. It also works on live messages and reply previews.
🔇 **Mute people in voice.** Hover someone's name in the voice channel list and click the 🔇. Only you stop hearing them.
🤖 **AI word filter (experimental).** Optionally uses Gemini to hide slurs and filter-evasion (leetspeak, spaced-out letters, etc.) on your screen only. This part is still untested, so it may not work yet. Muting does work.

Everything happens on your own computer. Other people can't see that you muted them, and nothing changes for anyone else.

**Install (Chrome / Edge / Brave)**
1. Download and unzip the file somewhere you'll keep it.
2. Go to chrome://extensions and turn on Developer mode (top right).
3. Click "Load unpacked" and select the unzipped "yapper-tools" folder.
4. Pin the extension, reload yapper.website, and click the icon to manage muted people.

**About the AI filter:** it's off by default. To try it, you need your own free Gemini API key (from Google AI Studio). If you turn it on, message text from channels you open is sent to Google, so only enable it if you're fine with that.
